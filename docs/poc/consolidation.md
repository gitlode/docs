# VitePress v2 への一本化

状態: 実装・ローカル検証完了。確認者: プロジェクトオーナー。
2026-11-19: オーナーが一本化を確認済み。次は [PoC 終了確認](closeout.md) と後続作業への引き継ぎ。

## 変更内容

VitePress 2.0.0-alpha.21 のみを残し、v1、Starlight、比較専用の依存と設定を削除しました。
過去の比較資料は判断の根拠として保持します。これは本番公開ではありません。

| 配置                 | 責務                                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| `src/publishing/`    | SSG 非依存: ソース取得、公開範囲の選別、翻訳状態、Markdown・リンク処理、静的配信、HTML 内の参照検証 |
| `src/ssg/vitepress/` | VitePress 依存: 入力生成、ビルド、生成 HTML の表示・言語・バージョン切替検証、検索検証              |
| `site/vitepress/`    | VitePress 設定、型定義、Vue テーマ                                                                  |
| `src/cli/site.ts`    | サイト用コマンドの入口                                                                              |

公開処理から VitePress を import せず、サイト側がその処理結果を利用します。
将来の SSG 追加を先回りしたプラグイン機構は作らず、責務と依存方向を明確にしました。
比較用の候補名を URL から除き、`/docs/next/ja/` のような構成に変更しました。

## 確認方法

```sh
npm run site:build
npm run preview
```

日本語 next は <http://127.0.0.1:4173/docs/next/ja/> です。停止は同じ端末で Ctrl+C。
自動確認には、終了時にサーバーを停止する `npm run site:verify` を使います。
旧 `previews:*`、`preview:vitepress*`、`preview:starlight` コマンドは廃止しました。

## 検証結果

- ロックファイルからの `npm ci --ignore-scripts` 成功。
- フォーマット、lint、TypeScript/Vue 型検査、43 テスト成功。
- stable/next の 2 ビルドと HTML 内リンク・アセット・断片参照、表示・翻訳状態の検証成功。
- 全 28 ページのバージョン切替先検証、HTTP スモーク検証成功。
- 32 件の検索プローブ成功。日本語 next の「全体」は 2 件ヒット。
- Edge のブラウザ確認で、未翻訳注釈、同じ文書への言語切替、別バージョンのトップへの切替、
  日本語検索結果からの節移動を確認。390px 幅でも注釈とバージョン切替が表示され、横にはみ出しなし。
- 検証用ブラウザと静的サーバーは終了し、使用ポートの解放を OS 側でも確認。

これらはローカル検証結果です。過去の 3 候補での Ubuntu CI 成功を、今回の構成の CI 成功と読み替えません。

## 依存関係と残る課題

旧構成由来の Vite/esbuild 不整合を解消し、Vite 8.3.8 に統一しました。
VitePress は別名パッケージではなく、通常の `vitepress` として固定しています。

2026-11-18 の npm audit は picomatch の ReDoS 指摘
([GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf))
に起因する high 7 パッケージを報告しました。7 件の独立した脆弱性という意味ではありません。
互換範囲内での更新では解消せず、強制修正が提示する VitePress v1 等へのダウングレードは行っていません。
ビルド・型検査の依存関係として残る指摘であり、本番準備時に再確認します。

本番の公開対象、画像等の明示的な取り込み、現在は外部参照となる文書リンク、stable 翻訳の管理方針、
翻訳品質の確認、デプロイは別途扱います。
