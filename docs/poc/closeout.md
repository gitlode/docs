## 達成したこと

## 実運用までに残るギャップ

| 項目             | PoC の到達点                                  | 後続で完了させること                                                       |
| ---------------- | --------------------------------------------- | -------------------------------------------------------------------------- |
| 公開範囲とリンク | 各版 6 文書。対象外へのリンクは GitHub を参照 | 本番の対象一覧を決め、サイト内参照を整備。リンク追跡による自動公開はしない |

| 翻訳             | next のサンプル、未翻訳と更新状態の判定       | stable の翻訳管理方針、品質レビュー、更新作業の手順を確定                  |
| ソース更新       | PoC 用の ref と commit を固定                 | 公開時の版と更新契機を決め、変更をレビューして更新する                     |

| 公開・運用       | `/docs/` 配下の完全な静的出力と CI 検証       | デプロイ、公開後検証、失敗時の復旧、運用手順を実装し、本番公開を承認する   |

監査の基準情報は 2026-11-18 時点の picomatch 由来 high 7 パッケージです。
現在の修正版の有無を断定する情報ではなく、後続作業開始時に再確認します。

## 引き継ぎの使い方

次のセッションは [current handoff](../handoff/current.md) から開始し、
[production readiness](../handoff/production-readiness.md) の順序・判断事項・完了条件に沿って進めます。
後続タスクには変更対象のファイルと検証方法を示し、実装済みの契約と未決事項を区別します。
`.generated/` 内の一時ファイルがなくても、追跡済みの設定とコマンドから再現できることを前提とします。

[開発環境の共通化提案](../proposals/development-environment.md)は別途検討し、後続開発を止めません。

## 終了判断の条件

- 一本化した実装の確認: オーナー確認済み。
- 後続作業への持ち越し範囲: オーナー確認済み。
- 引き継ぎ資料の整備、最終構成の CI、後続 PR の提示: 完了。
- PR のレビュー・squash merge と PoC 終了の明示的な承認: オーナーの判断待ち。

PoC の終了を、本番公開の承認や本番品質の保証として扱いません。
